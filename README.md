# +1 Jump Skate Escape
A Roblox skateboarding progression game with two worlds, ramp launches, mid-air jumps, training areas, and obstacle courses. Earn XP, improve your movement, collect wins, and unlock upgrades as you progress. 

## Quick Start Guide
1. Download the **.rbxl** file in the repository
2. Double click the downloaded file (Roblox Studio MUST be installed). Alternatively, open a new place and go to **File > Open from File** and select `+1 Jump Skate Escape REDACTED.rbxl`
3. Choose **File > Publish to Roblox As..** and create a new experience under your own account or group of your choice. Enter its name and other details, then publish
4. Open **File > Experience Settings > Security ** If you are on a later version of studio, this may come up as **Game Settings**
5. Turn on **Enable Studio Access to API Services** and click **Save**
6. You are good to go!

## Features
- Two worlds with their own courses, shops, training areas and portals
- Movement-based XP, levels and speed progression
- Ramp boosts, water and lava hazards, sweeping lasers and sinking platforms
- Win pads, board unlocks, rebirths, trails and speed/jump upgrades
- Training grounds with different requirements and XP multipliers
- Race mode which happens every 5 minutes
- Daily rewards, leaderboards, tutorials, revives and monetisation
- Data saving, admin systems and commands

## Troubleshooting
| Symptom | Check |
| --- | --- |
| Saves fail or profiles do not load in Studio | Publish first, enable Studio API access, and inspect Output for ProfileStore/data-store errors. |
| Animations, sounds, or meshes are missing | Inspect Output for asset-loading and permission errors. |
| Players cannot join the published game | Check its audience, account/group permissions, and current Roblox publishing requirements. |
